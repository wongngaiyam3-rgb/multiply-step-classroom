# 乘法小步子｜數塊建造所

正式網址：https://wongngaiyam3-rgb.github.io/multiply-step-classroom/multiplication-lab/

小四乘法教學，沿用除法小步子的單一任務節奏。兩位數×兩位數先乘十位、再乘個位；兩位數×三位數先乘百位、再乘十位與個位，最後按欄相加。每條路線 8 題，包含連續進位、乘數中間及末位為 0。

- 4A–4C／1–25 號入口，全部活動先報到。班別學號是自選身分，並非認證。
- 十條、個粒、位值放大及可反覆交換的進位圖解；直式黃框逐步對位。
- 答對中央鼓勵，學生按「我準備好了」才繼續。錯答可修正、按需提示、重做上一步、朗讀與休息。
- 獨立練習不預顯示部分積；小白板支援手寫、撤銷及清空。
- 學習進度、白板、首次／最近答案、提示及修正次數只存本機，依網站、學年、班別與學號分隔。切換學生停止舊會話。每個身分最多保留最近 80 次完成紀錄，白板每題最多 40 筆、每筆 180 點。
- 「我的紀錄」只顯示目前自選班號的本機資料，可下載 CSV；不提供全班教師後台或跨裝置同步。
- 右上角小科共用既有 Supabase 安全問答及教師監察服務；不把學習答案、白板或其他程式的憑證送往小科。

## 發布與驗證

Buildless HTML/CSS/ES modules，GitHub Pages 直接提供本目錄。`node --test tests/math.test.mjs` 驗證 89,100 組合法乘法、定位零、每欄進位、75 個班號及香港學年邊界。`node prepare-preview.mjs` 只準備忽略的本機 `dist`，供受管預覽。

瀏覽器實測 23×14 全部 13 步（含錯答→提示→改正及紀錄）、58×204 全部 19 步（含十位為 0、連續進位）、獨立模式與白板筆畫、換學生資料分隔。小科只在已登記的正式網址提供服務；本機預覽不在 API 的來源白名單。

老師仍應配合學生口述與紙筆觀察理解程度。本機班號選擇不適合作為受保護的個人成績驗證。
